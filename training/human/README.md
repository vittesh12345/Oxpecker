# A model of human choices

This kit trains a small open model to predict what **people** choose, not what a rule says is
correct. It follows [Centaur](https://huggingface.co/marcelbinz/Llama-3.1-Centaur-70B)
(Binz et al.), a model fine-tuned on Psych-101: transcripts of 160 psychology experiments with
60,092 participants and over 10 million choices, each marked like `You press <<J>>.`

It then tests the model on decisions from outside the lab: the yes/no answers people give to pay
and scheduling proposals in Oxpecker's research mode, which uses the same transcript format
(`You answer <<yes>>.`).

| Script | What it does |
| --- | --- |
| `prepare.py` | Streams Psych-101 and keeps a sample from every experiment, holding out about 1 participant in 20 |
| `train.py` | LoRA fine-tuning; the loss covers only people's choices |
| `evaluate.py` | Held-out Psych-101 likelihood, and accuracy on Oxpecker yes/no answers |
| `publish.py` | Writes a model card from the measured scores and uploads the adapter |

## Measures

- **Psych-101 held-out participants:** average negative log-likelihood per human choice. Lower
  means the model expected what people actually did. This is the measure Centaur reports.
- **Oxpecker decisions:** how often the model's more likely answer matches the person's, its log
  loss, and the score of always guessing the more common answer. Beating that last number is
  the minimum bar.

## Run it

The free T4 on Google Colab is enough for the default Qwen2.5-0.5B model: open
`oxpecker_human_colab.ipynb` from this folder. On your own NVIDIA GPU, from the repository root:

```bash
pip install -r training/requirements.txt
```

```bash
python training/human/prepare.py --output runs/human/data
```

```bash
python training/human/evaluate.py --psych101 runs/human/data/heldout.jsonl --oxpecker paysim-transcripts.jsonl --output runs/human/eval-base.json
```

```bash
python training/human/train.py --data runs/human/data/train.jsonl --output runs/human
```

```bash
python training/human/evaluate.py --adapter runs/human/adapter --psych101 runs/human/data/heldout.jsonl --oxpecker paysim-transcripts.jsonl --output runs/human/eval-tuned.json
```

```bash
python training/human/publish.py --run runs/human --repo <your-hf-name>/human-choice-qwen2.5-0.5b-lora
```

`paysim-transcripts.jsonl` is the file from **Practice log → Recorded answers → Download
transcripts** in the app. Leave out `--oxpecker` until you have some.

## Using Oxpecker data for training

By default Oxpecker answers are only used to test the model, which keeps that test honest. Once
you have answers from many people, split them by participant, keep one group for testing, and add
the rest to training with `--extra`. Never train and test on the same people's answers.

## What has been checked

Every step ran on a CPU with a tiny untrained model, small stand-in Psych-101 data and Oxpecker
transcripts generated by the app's own export code. That checks the code, not the quality.
The real Psych-101 download and GPU training have not been run yet. The choice-masking logic is
tested in `test_choices.py`:

```bash
python -m unittest discover training/human
```

## Limits

A sub-billion-parameter model trained on a sample of Psych-101 will be much weaker than Centaur's
70 billion parameters. Psych-101 is mostly lab tasks, so the Oxpecker test is the real check on
whether anything carries over to everyday decisions. A model like this describes average
tendencies; it should not be used to judge or make decisions about any real person.
